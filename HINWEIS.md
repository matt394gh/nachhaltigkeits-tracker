# Testbilder für den fairen Modellvergleich

Das Kriterienraster verlangt "nachvollziehbare Kriterien; faire
Testbedingungen; begründetes Fazit" für den Vergleich der beiden
Versionen. So gehst du vor:

## 1. Testset zusammenstellen

- 15-20 Fotos von Kleidungsstücken/Etiketten sammeln und **in diesen
  Ordner** legen (Bilder können auch in der Doku-Tabelle nummeriert werden).
- Für jede Marke/Kategorie mindestens 3 Fotos, damit der Vergleich
  aussagekräftig ist.
- Dieselben Fotos werden für **beide** Versionen benutzt - das ist der
  Kern der fairen Testbedingungen.

## 2. Testablauf

1. Foto in der App hochladen, Version A laufen lassen, Ergebnis notieren.
2. Dasselbe Foto mit Version B laufen lassen, Ergebnis notieren.
3. In der App sammelt die Ergebnis-Historie beide Zeilen automatisch -
   am Ende als Tabelle in die Dokumentation übernehmen.

## 3. Vergleichskriterien (in der Doku begründen)

| Kriterium | Wie gemessen? |
|---|---|
| Trefferquote | Anteil der Testfotos, bei denen die richtige Marke/Kategorie in die DB kam |
| Geschwindigkeit | grobe Stoppuhr bzw. subjektive Reaktionszeit (Sekunden) |
| Konfidenz | Version A zeigt eine Wahrscheinlichkeit, Version B nicht (Unterschied diskutieren!) |
| Voraussetzungen | Trainingsdaten-Aufwand vs. 500 MB Download beim ersten Start |
| Grenzen | was jeweils nicht funktioniert hat (Beispiele sammeln) |

## 4. Fazit-Vorlage

"Version A ist besser bei ___, weil ___. Version B ist besser bei ___,
weil ___. Für den Einsatzzweck ___ passt daher Version ___."
